Zero-Knowledge Architecture

Decentralized P2P & IPFS File Transfer

WORMHOLE enables wire-speed, end-to-end encrypted file sharing between peers using direct WebRTC DataChannels, serverless ZEN signaling, and decentralized IPFS staging fallback.

⚡

Direct P2P Stream (WebRTC) Default

Inspired by FilePizza, files are streamed directly between peers using binary RTCDataChannel in 64KB chunks.

  • ✓ Zero Base64 & Zero DB Flooding: Wire-speed transfer over UDP/SCTP.
  • ✓ Flow Control: Native backpressure management (bufferedAmount).
📡

Serverless Signaling via ZEN GunDB

The ZEN distributed graph database acts as a decentralized rendezvous bus, eliminating reliance on proprietary WebSocket or Socket.io servers.

  • ✓ Lightweight Handshake (~2-3 KB): SDP Offer/Answer & ICE candidates.
  • ✓ Ephemeral Coordination: Rendezvous metadata cleaned up upon handshake.
☁️

IPFS Relay (delay) --ipfs

When peers are behind symmetric enterprise NATs or asynchronous delivery is required, encrypted files are staged on IPFS via the companion relay scobru/delay.

  • ✓ Automatic Cache Purge: Receiver confirmation triggers automated unpinning.
  • ✓ Custom Relay Support: Run your own self-hosted delay instance anytime.
🔒

End-to-End Encryption (E2EE) AES-GCM

All files are encrypted client-side using military-grade AES-GCM (256-bit) with PBKDF2 key derivation.

  • ✓ Zero-Knowledge Mnemonic: The code (e.g. 82-gentle-bird) is both the address and the key.
  • ✓ Confidentiality: Relays and signaling nodes never see plaintext or filenames.

🔄 How Wormhole Works Under the Hood

01

Local Encryption

Sender generates mnemonic code and encrypts file via AES-256-GCM in the browser or terminal.

02

ZEN Discovery

Receiver inputs code. Peers discover each other over ZEN graph and exchange WebRTC SDP & ICE.

03

Direct Stream

Encrypted binary chunks travel at wire-speed through WebRTC DataChannel (or IPFS fallback).

04

Local Decryption

Receiver decrypts stream in memory and saves file. Signaling state & relay caches auto-purge.

Command Line Interface

Wormhole CLI (wh)

The CLI binary is named wh to prevent collisions with magic-wormhole. Fast, lightweight, and sharing the exact universal core with this browser dashboard.

Global Installation npm
npm install -g wormhole

Gives you direct access to the global wh command from any terminal shell.

Run Instantly (Zero Install) npx
npx wh send <file-path>

Zero disk setup required. Runs on-demand anywhere Node.js is installed.

🛠️ CLI Command Reference

Command Description Action
wh send <file> [options] Encrypts and streams file via direct WebRTC P2P (or IPFS relay).
wh receive <code> [options] Connects to sender, downloads stream, and decrypts using sync code.
wh list Lists currently active transfers (experimental).

⚙️ CLI Options & Flags

Flag Shorthand Description Default
--p2p - Use direct WebRTC DataChannel streaming. true
--ipfs, --relay - Send via IPFS relay instead of direct P2P. false
--url <url> -u Custom IPFS relay URL. https://delay.scobrudot.dev
--token <token> -t Bearer auth token for IPFS relay upload. shogun2025
